# 随想录 · 无名杀扩展

无名杀（noname）1.11.x 的武将扩展，收录「势 小乔」「神 马超」与再开发版「魔 孙权」三名武将。所有代码遵循无名杀 async 写法与对象参数规范，素材随扩展自包含分发。

## 武将一览

| 武将 | 势力 | 体力 | 技能 |
| --- | --- | --- | --- |
| 势 小乔（`suixiang-shi_xiaoqiao`） | 吴 | 3/3 | 和韵 `suixiang_heyun`、音洄 `suixiang_yinhui` |
| 神 马超（`suixiang-mb_shen_machao`） | 神 | 4 | 驭雳 `suixiang_mb_yuli`、霆威 `suixiang_mb_tingwei`、寂灭 `suixiang_mb_jimie` |
| 魔 孙权（`suixiang-dm_sunquan`） | 魔 | 4 | 权御 `suixiang_olquanyu`、天恩 `suixiang_oltianen`、乾纲 `suixiang_olqiangang` |

## 技能

### 和韵（势 小乔）

出牌阶段限两次，你可以选择自己或一名与你拥有相同技能的角色，令其失去一个你选择的武将牌上技能（装备技能除外），然后其摸两张牌。每回合你首次进入濒死时，你可以对自己发动此技能，失去一个你选择的武将牌上技能（装备技能除外），摸两张牌，然后回复至 1 点体力。

### 音洄（势 小乔）

每轮开始时，或当你失去技能时，你可以选择一名其他角色，获得其武将牌上当前拥有的一个技能（装备技能除外）。获得的技能会刷新其状态（发动次数、限定技等重置），且不会因再次发动而失去已获得的技能。

### 驭雳（神 马超 · 锁定技）

造成的伤害改为雷电伤害，若原版伤害已经是雷电伤害则伤害增加1点。当造成高于1点的雷电伤害时会额外对目标相邻的角色造成一半伤害（向下取整）。受到雷电伤害时免疫雷电伤害并摸等量牌。

实现细节：溅射伤害为无牌雷电伤害、来源为神马超；溅射伤害不吃"已是雷电则+1"，但若溅射值仍高于1点会继续向相邻角色逐层扩散（左右邻座为同一人时去重）；溅射伤害同样受驭雳免伤摸牌影响（打到神马超自己时免疫并摸牌）；被免疫（防止）的伤害不再继续扩散。

### 霆威（神 马超 · 锁定技）

使用伤害牌指定目标后，你获得4个"霆"标记，然后你可以选择以下任意项（每选一项消耗1个"霆"标记）：1.目标本回合非锁定技失效；2.目标交给你一张牌；3.此伤害牌对目标造成的伤害+1；4.本回合使用【杀】的次数上限+1；5.目标进入连环状态。每项效果对该牌的所有目标生效。

实现细节：伤害牌含【杀】【决斗】【火攻】【南蛮入侵】【万箭齐发】等；一次使用只触发一次，选择任意项（可取消只拿标记）；第2项目标无牌时可选但不生效；第3项沿用引擎 `customArgs.extraDamage` 通道；第4项通过临时子技能增加【杀】使用上限；第5项目标进入连环状态。

### 寂灭（神 马超 · 限定技）

出牌阶段结束时，你可以弃8个"霆"标记，对一名角色造成等于其体力上限的伤害。然后当你【驭雳】的两项均执行后，此技能视为未发动过。

实现细节：驭雳的状态记录（造成雷伤/受到雷伤）沿用原版机制；寂灭发动后，驭雳两项再次全部触发时自动重置寂灭。

### 权御（魔 孙权 · 锁定技，原版重构）

每轮开始时，所有角色同时为你选择两项"权御"效果（两项不可相同；辟邪、紫电与流星本局每人限选一次），然后你摸X张牌（X为其中与你本轮选择相同的角色数，不设上限）。你使用伤害牌指定目标后，执行全部"权御"效果：白虹：基础伤害+1；青冥：每层可额外选择一个目标（自由选择数量，可随时停止）；辟邪：无视防具；紫电：不可响应；百里：额外结算一次；流星：无次数限制。所有角色的选择永久累计并强化你。

实现细节：白虹/青冥/百里可跨轮重复叠加；效果池为所有角色（含已阵亡）的标记层数之和；额外目标逐层询问、每层限选1个、点取消即停止；效果执行统一在 `useCard2` 时机（引擎官方加目标通道）。

### 天恩（魔 孙权 · 锁定技，无次数与唯一目标限制）

你使用牌指定一名角色为目标后（多目标牌按目标逐个触发）：若你与其本轮的"权御"选择存在相同效果，你从牌堆获得一张不计入手牌上限的【杀】；若存在不同效果，你随机弃置其一张牌，然后对其发动一次"权御"。仅一项相同时，两项效果均触发。

### 乾纲（魔 孙权 · 主动技）

出牌阶段，你可失去〖天恩〗并入魔（每轮结束未造成伤害则失去1点体力），然后其他角色根据其拥有的"权御"标记数获得效果：2枚，其受到伤害后，你摸一张牌；4枚，其进入濒死时，只能使用【酒】回复体力；6枚，回合外其非锁定技失效；8枚，其攻击距离、出杀次数与手牌上限始终为0。标记数按六项层数总和计算，debuff 随标记增长动态升级。

实现细节：4枚效果在 `recoverBegin` 时机直接取消回复事件（卡牌与技能回复全覆盖，豁免【酒】）；6枚效果采用缠怨同款 `skillBlocker`；8枚效果通过 `attackRange`/`cardUsable`/`maxHandcard` 三个 mod 实现。

## 安装

1. 下载本仓库最新 [Release](https://github.com/keepermttl/noname-suixianglu/releases) 附件（`随想录-vX.Y.Z.zip`）解压，将 `随想录` 文件夹放入无名杀游戏目录的 `extension/` 下；
2. 或直接下载仓库源码，取 `extension.js`、`info.json`、`audio/`、`image/`、`shixiaoqiao/`；
3. 重启游戏，在「选项 → 扩展」中启用「随想录」。

## 依赖与兼容

- 必需：无。
- 可选 `无名美化`：启用时，和韵/音洄的技能选择使用其势小乔 Vue 特效面板（缺失时自动回退引擎原生面板）；乾纲入魔时播放其 Spine 入魔特效与官方语音（缺失时静默跳过，音频已内置）。
- 可选 `十周年UI`：启用时，神 马超与魔 孙权自动共享原版武将的动态皮肤（天神威马超系列 / 魔孙权经典形象）。
- 可选 `无名美化` + `十周年UI`：两者同时启用且开启「手杀神马超特效」时，寂灭发动播放原版 Spine 大招动画。
- 可选 `千幻聆音`：启用时，神 马超与魔 孙权的皮肤语音共享映射到原版同名技能。

## 素材说明

- 神 马超的立绘、驭雳 6 条 / 霆威 4 条 / 寂灭 4 条技能语音与阵亡语音，均为原版手杀神马超官方资源的副本。
- 魔 孙权的立绘、权御 2 条 / 天恩 3 条 / 乾纲 3 条技能语音与阵亡语音、官方乾纲语音及"秉均持衡"皮肤素材，均为原版 OL 魔孙权官方资源的副本。
- 以上素材随扩展自包含分发，不依赖游戏本体文件；素材版权归原游戏所有。代码部分以 MIT 协议开源。


## 开发

- 代码遵循无名杀 1.11.x async 写法与对象参数规范；
- 命名规范：所有武将/技能编码以 `suixiang` 为前缀，带名称外前缀的武将按 `扩展词缀-武将词缀_武将名` 编码；
- 版本历史（每个版本均有对应 `release-vX.Y.Z` 分支与 GitHub Release）：v1.1.0 神 马超·驭雳 → v1.2.0 霆威 → v1.3.0 寂灭（神 马超齐备）→ v1.3.5 魔 孙权（权御重构+天恩）→ v1.3.7 乾纲 → v1.3.9 魔势力修正 → v1.3.10 天恩判定优化。
