# 随想录（无名杀扩展）

无名杀（noname）1.11.6 的原创武将扩展。

## 内容

| 武将 | 势力 | 体力 | 技能 |
| --- | --- | --- | --- |
| 势 小乔（`suixiang-shi_xiaoqiao`） | 吴 | 3/3 | 和韵 `suixiang_heyun`、音洄 `suixiang_yinhui` |

### 和韵

出牌阶段限两次，你可以选择自己或一名与你拥有相同技能的角色，令其失去一个你选择的武将牌上技能（装备技能除外），然后其摸两张牌。每回合你首次进入濒死时，你可以对自己发动此技能，失去一个你选择的武将牌上技能（装备技能除外），摸两张牌，然后回复至 1 点体力。

### 音洄

每轮开始时，或当你失去技能时，你可以选择一名其他角色，获得其武将牌上当前拥有的一个技能（装备技能除外）。获得的技能会刷新其状态（发动次数、限定技等重置），且不会因再次发动而失去已获得的技能。

## 安装

1. 将本目录（`随想录`）放入无名杀游戏目录的 `extension/` 文件夹；
2. 或在游戏内「获取扩展 → 导入扩展」选择本文件夹；
3. 重启游戏，在「选项 → 扩展」中启用「随想录」。

## 依赖

- 必需：无。
- 可选：`无名美化` 扩展——启用时，和韵/音洄的技能选择会使用其势小乔 Vue 特效面板；未启用时自动回退引擎原生面板。

## 目录结构

```
随想录/
├── extension.js           # 扩展主文件（武将+技能定义）
├── info.json              # 扩展信息
├── audio/                 # 技能/阵亡语音
├── image/character/       # 武将立绘
└── shixiaoqiao/           # Vue 技能选择面板（移植自无名美化，可选依赖）
```
