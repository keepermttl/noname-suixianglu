## 新增武将与技能

### 势 赵云（蜀，男，4/4体力）

势赵云初始拥有〖武翊〗和〖摧锋〗；〖武翊〗记录达到两种基本牌牌名后获得〖龙魂〗。本扩展为其使用独立武将与技能 ID，并内置立绘、阵亡语音和技能语音。

#### 武翊（持恒技）

记录你本局使用或打出的基本牌牌名种类，并按记录种类数逐步解锁效果：达到1种，你使用牌无距离和次数限制；达到2种，获得〖龙魂〗；达到3种，你的回合内其他角色的非持恒技失效；达到4种，你的手牌数始终为4。

#### 龙魂（武翊衍生技）

你可以将一至两张牌按花色当作基本牌使用或打出：红桃当【桃】，方块当火【杀】，梅花当【闪】，黑桃当【无懈可击】。若以此法使用两张牌，使用【桃】令目标角色增加1点体力上限；使用火【杀】额外结算两次；使用【闪】令此【杀】的使用者随机弃置两张牌；使用【无懈可击】则此牌不能被响应，且你获得被响应的牌。龙魂技能代码已移植进随想录，不依赖极略扩展。

#### 摧锋（持恒技）

每轮限两次。每个回合开始时，你可以对一名其他角色使用【决斗】。拥有〖武翊〗后解锁“未记录”效果；〖武翊〗记录【杀】、【闪】、【酒】、【桃】后，分别永久解锁对应效果：未记录，造成伤害后随机记录一个尚未记录的基本牌名；【杀】，此【决斗】伤害+X（X为〖武翊〗记录的牌名数）；【闪】，此【决斗】不可响应；【酒】，其受到此【决斗】伤害后，其下一张使用或打出的牌无效；【桃】，其受到此【决斗】伤害后，直到其下一个回合结束阶段开始时不能回复体力。势赵云的语音按原版台词分配：〖武翊〗按记录阶段播放前四句，〖龙魂〗使用第五、六句，〖摧锋〗使用完整四句。

### 谋 诸葛亮（蜀，男，3/3体力）

谋诸葛亮初始拥有改版〖看破〗和使命技〖火计〗；完成火计使命后失去火计并获得〖观星〗与〖空城〗。角色接入诸葛亮动皮配置及 `sp_zhugeliang` 皮肤库，技能与阵亡语音随扩展提供。

#### 看破（改版）

游戏开始时，你选择0至4个当前牌堆中的牌名记录（可以重复）。其他角色使用记录牌名的牌时，你可以移去一项对应记录，令此牌对所有目标无效并摸一张牌，然后你可以记录一个不同于刚移去牌名的牌名；补记可以与现有记录重复。若〖火计〗使命失败，则被无效牌的使用者的非锁定技失效至下一轮开始，并受到1点无来源伤害。

#### 火计（使命技）

出牌阶段限一次，你可以选择一名其他角色，对其与其势力相同的其他角色各造成1点火焰伤害。每次结算中若至少有一名角色因此进入濒死，结算结束后你获得一次可在本出牌阶段随时使用的额外发动机会；同一次结算无论多少人进入濒死，都只提供一次机会。额外发动若再次满足条件，可以继续链式追加；本回合第N次额外发动造成的伤害增加N点。成功：准备阶段，若任意角色曾因火焰伤害进入濒死，你失去〖火计〗并获得〖观星〗、〖空城〗。失败：使命成功前你进入濒死时，将体力回复至上限，然后〖火计〗失效。

#### 观星（火计衍生技）

锁定技，你的手牌数始终为0，牌堆顶七张牌仅对你可见。每当你从手牌区弃置牌后，你将这些牌置于武将牌上，称为“星”。你可以如同使用或打出手牌般使用或打出“星”和牌堆顶七张牌；以此法使用牌堆顶的牌无距离和次数限制。每名角色的准备阶段，你可以调整牌堆顶七张牌的顺序，并将其中任意张置于牌堆底。

#### 空城（火计衍生技）

锁定技，你没有手牌时，不能成为【杀】或【决斗】的目标。当你即将受到伤害时，你可以将三张“星”置入弃牌堆，令此伤害无效。

## 其他武将技能

### 和韵（势 小乔）

出牌阶段限两次，你可以选择自己或一名与你拥有相同技能的角色，令其失去一个你选择的武将牌上技能（装备技能除外），然后其摸两张牌。每回合你首次进入濒死时，你可以对自己发动此技能，失去一个你选择的武将牌上技能（装备技能除外），摸两张牌，然后回复至 1 点体力。

### 音洄（势 小乔）

每轮开始时，或当你失去技能时，你可以选择一名其他角色，获得其武将牌上当前拥有的一个技能（装备技能除外）。获得的技能会刷新其状态（发动次数、限定技等重置），且不会因再次发动而失去已获得的技能。

### 驭雳（神 马超 · 锁定技）

造成的伤害改为雷电伤害，若原版伤害已经是雷电伤害则伤害增加1点。当造成高于1点的雷电伤害时会额外对目标相邻的角色造成一半伤害（向下取整）。受到雷电伤害时免疫雷电伤害并摸等量牌。

实现细节：溅射伤害为无牌雷电伤害、来源为神马超；溅射伤害不吃"已是雷电则+1"，但若溅射值仍高于1点会继续向相邻角色逐层扩散（左右邻座为同一人时去重）；溅射伤害同样受驭雳免伤摸牌影响（打到神马超自己时免疫并摸牌）；被免疫（防止）的伤害不再继续扩散。

### 霆威（神 马超 · 锁定技）

使用伤害牌指定目标后，你获得4个"霆"标记，然后你可以选择以下任意项（每选一项消耗1个"霆"标记）：1.目标本回合非锁定技失效；2.目标交给你一张牌；3.此伤害牌对目标造成的伤害+1；4.本回合使用【杀】的次数上限+1；5.目标进入连环状态。每项效果对该牌的所有目标生效。

实现细节：伤害牌含【杀】【决斗】【火攻】【南蛮入侵】【万箭齐发】等；一次使用只触发一次，选择任意项（可取消只拿标记）；第2项目标无牌时可选但不生效；第3项沿用引擎 `customArgs.extraDamage` 通道；第4项通过临时子技能增加【杀】使用上限；第5项目标进入连环状态。

### 寂灭（神 马超 · 限定技）

出牌阶段结束时，你可以弃8个"霆"标记，对一名角色造成等于其体力上限的伤害。然后当你【驭雳】的两项均执行后，此技能视为未发动过。

实现细节：驭雳的状态记录（造成雷伤/受到雷伤）沿用原版机制；寂灭发动后，驭雳两项再次全部触发时自动重置寂灭。

### 权御（魔 孙权 · 锁定技，原版重构）

每轮开始时，所有角色同时为你选择两项"权御"效果（两项不可相同；辟邪、紫电与流星本局每人限选一次），然后你摸X张牌（X为其中与你本轮选择相同的角色数，不设上限）。你使用伤害牌指定目标后，执行全部"权御"效果：白虹：基础伤害+1；青冥：每层可额外选择一个目标（自由选择数量，可随时停止）；辟邪：无视防具；紫电：不可响应；百里：额外结算一次；流星：无次数限制。所有角色的选择永久累计并强化你。

实现细节：白虹/青冥/百里可跨轮重复叠加；效果池为所有角色（含已阵亡）的标记层数之和；额外目标逐层询问、每层限选1个、点取消即停止；效果执行统一在 `useCard2` 时机（引擎官方加目标通道）。

### 天恩（魔 孙权 · 锁定技，无次数与唯一目标限制）

你使用牌指定一名角色为目标后（多目标牌按目标逐个触发）：若你与其本轮的"权御"选择存在相同效果，你从牌堆获得一张不计入手牌上限的【杀】；若存在不同效果，你随机弃置其一张牌，然后对其发动一次"权御"。仅一项相同时，两项效果均触发。

### 乾纲（魔 孙权 · 主动技）

出牌阶段，你可失去〖天恩〗并入魔（每轮结束未造成伤害则失去1点体力），然后其他角色根据其拥有的"权御"标记数获得效果：2枚，其受到伤害后，你摸一张牌；4枚，其进入濒死时，只能使用【酒】回复体力；6枚，回合外其非锁定技失效；8枚，其攻击距离、出杀次数与手牌上限始终为0。标记数按六项层数总和计算，debuff 随标记增长动态升级。

实现细节：4枚效果在 `recoverBegin` 时机直接取消回复事件（卡牌与技能回复全覆盖，豁免【酒】）；6枚效果采用缠怨同款 `skillBlocker`；8枚效果通过 `attackRange`/`cardUsable`/`maxHandcard` 三个 mod 实现。

## 安装

1. 下载本仓库最新 [Release](https://github.com/keepermttl/noname-suixianglu/releases) 附件（`随想录-vX.Y.Z.zip`）解压，将 `随想录` 文件夹放入无名杀游戏目录的 `extension/` 下；
2. 或直接下载仓库源码，取 `extension.js`、`info.json`、`audio/`、`image/`、`shixiaoqiao/`；
3. 重启游戏，在「选项 → 扩展」中启用「随想录」。

## 依赖与兼容

- 必需：无。
- 可选 `无名美化`：启用时，和韵/音洄的技能选择使用其势小乔 Vue 特效面板（缺失时自动回退引擎原生面板）；乾纲入魔时播放其 Spine 入魔特效与官方语音（缺失时静默跳过，音频已内置）。
- 可选 `十周年UI`：启用时，神 马超与魔 孙权自动共享原版武将的动态皮肤（天神威马超系列 / 魔孙权经典形象）。
- 可选 `无名美化` + `十周年UI`：两者同时启用且开启「手杀神马超特效」时，寂灭发动播放原版 Spine 大招动画。
- 可选 `无名美化`：开启「手杀势赵云特效」时，随想录势赵云会复用原版势赵云的觉醒、出牌和龙魂牌面特效，不会重复加载原版技能。
- 可选 `皮肤切换` / `十周年UI`：随想录势赵云注册为 `pot_zhaoyun` 的动皮别名；本体没有单独动皮配置时回退使用赵云的动皮配置。
- 可选 `千幻聆音`：神 马超、魔 孙权和势 赵云的皮肤语音共享映射到原版技能；势赵云的龙魂语音映射到武翊语音组。
- 可选 `十周年UI` / `千幻聆音`：谋 诸葛亮分别共享诸葛亮动皮配置与 `sp_zhugeliang` 皮肤库；看破语音映射到原版看破语音组。

## 素材说明

- 神 马超的立绘、驭雳 6 条 / 霆威 4 条 / 寂灭 4 条技能语音与阵亡语音，均为原版手杀神马超官方资源的副本。

- 谋 诸葛亮使用本体 `sb_sp_zhugeliang` 的原画、阵亡语音及看破技能语音；观星、空城语音沿用本体 `sbguanxing`、`sbkongcheng` 资源。火计、加强版看破、观星与空城均已接入。
- 势 赵云使用用户提供的原画、阵亡语音及完整官方技能语音；武翊按记录牌名阶段播放第1–4句，衍生技龙魂播放第5–6句，摧锋使用4句官方语音。

## 开发

- 代码遵循无名杀 1.11.x async 写法与对象参数规范；
- 命名规范：所有武将/技能编码以 `suixiang` 为前缀，带名称外前缀的武将按 `扩展词缀-武将词缀_武将名` 编码；
- 版本历史（每个版本均有对应 `release-vX.Y.Z` 分支与 GitHub Release）：v1.1.0 神 马超·驭雳 → v1.2.0 霆威 → v1.3.0 寂灭（神 马超齐备）→ v1.3.5 魔 孙权（权御重构+天恩）→ v1.3.7 乾纲 → v1.3.9 魔势力修正 → v1.3.10 天恩判定优化 → v1.3.11 势 赵云·武翊 → v1.3.12 势 赵云·摧锋 → v1.3.13 摧锋限制与伤害判定修复 → v1.3.14 势赵云资源、技能语音与美化兼容 → v1.3.15 修复势赵云龙魂美化动画在 StepCompiler 下的运行时错误 → v1.3.16 谋诸葛亮及其使命技、手牌区星牌与观星牌堆交互。
